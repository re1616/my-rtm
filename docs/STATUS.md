## Известные ограничения после M3b

- Исправлено в M3a: перемещение задачи обратно во «Входящие» синхронизируется (метка `sys-inbox` заменяется на id серверных входящих при отправке); «Входящие» больше не показывают задачи всех списков; снятие отметки выполнения; новая задача видна сразу; экранированный текст `\u…` в интерфейсе.
- Виртуализация длинных списков (5 000 задач, TanStack Virtual), полнотекстовый поиск по заметкам в Web Worker, локализация EN и ленивые чанки — метрики раздела 3.3, не входили в F1–F5; поиск сейчас по названию через язык запросов.
- Локализация сделана своим модулем (gettext-подход: русская строка — ключ, `Intl.PluralRules` для множественного числа), а не ICU MessageFormat.
- Подзадачи следующего экземпляра повторяющейся задачи не копируются (теги и заметки копируются).
- Серверные «Входящие» определяются по имени списка `Inbox`; пользовательский список с таким же именем сервер считает входящими.
