# Спецификация: менеджер задач (Web + Android)

Oct 17, 2026 · @Ro

## 1. Обзор продукта

Продукт — кроссплатформенный менеджер задач (рабочее название **Taskly**) с функциональным паритетом Remember The Milk: те же сущности, сценарии, логика экранов и синтаксис быстрого ввода. Визуальная идентичность — имя, логотип, палитра, иконки, иллюстрации и тексты интерфейса — собственная: копирование фирменного стиля RTM исключено.

**Цели**

- Дать пользователю «выгрузить задачи из головы» за секунды: одна строка ввода с умным разбором дат, тегов, приоритетов и списков.
- Не дать забыть: надёжные напоминания по push, email и в веб-уведомлениях.
- Мгновенная синхронизация между веб-версией и Android, работа офлайн.
- Гибкая организация для продвинутых: теги, умные списки на языке запросов, подзадачи.

**Платформы в объёме**

| Платформа | Минимальная версия | Форм-фактор |
| --- | --- | --- |
| Веб-приложение (SPA) | Chrome/Edge/Firefox/Safari, две последние мажорные версии | Десктоп ≥ 1024 px, адаптив до 360 px |
| Android-приложение | Android 8.0 (API 26), target API 35 | Телефон, планшет, складные устройства |

**Вне объёма v1:** iOS, десктоп-клиенты, Apple Watch / Wear OS, расширения браузера, интеграция с Outlook (план v2).

**Целевые пользователи:** занятые профессионалы и сторонники GTD, семьи и малые команды с общими списками (покупки, дела по дому, проекты).

## 2. Модель данных

Все сущности принадлежат пользователю, имеют UUID, поля `created_at`, `updated_at`, `deleted_at` (мягкое удаление) и `version` для синхронизации.

| Сущность | Ключевые поля | Примечания |
| --- | --- | --- |
| User | email, имя, часовой пояс, язык, формат даты, первый день недели, тариф (free/pro), настройки напоминаний | Один аккаунт на email; OAuth Google |
| List | name, owner\_id, archived, sort\_order, is\_smart, filter\_query, default\_due, color | Системные списки: «Входящие», «Отправленные» (задачи, переданные другим) |
| Task | name, list\_id, parent\_id, priority (1/2/3/none), due\_date, due\_has\_time, start\_date, estimate (минуты), repeat\_rule, url, location\_id, completed\_at, postponed\_count, assignee\_id, source | parent\_id → подзадачи (Pro), глубина до 3 уровней |
| Tag | name (уникально в аккаунте), color (Pro) | Связь многие-ко-многим TaskTag |
| Note | task\_id, title, body (markdown), author\_id | Несколько заметок на задачу |
| Location | name, lat, lng, address, radius\_m | Используется для «задачи рядом» |
| Reminder | task\_id, offset\_min или абсолютное время, channel (push/email/web) | Несколько напоминаний на задачу |
| Attachment | task\_id, provider (gdrive/dropbox/upload), url, name, size | Pro |
| Contact / Share | list\_id, user\_id, permission (view/edit), status | Общие списки и передача задач |
| SavedSearch | = List с is\_smart = true | Хранит строку запроса |
| Activity | entity, action, actor, diff, ts | Лента изменений в общих списках |

**Правило повтора** хранится в RRULE (RFC 5545) плюс флаг режима: `every` (от плановой даты) или `after` (от даты выполнения). При завершении повторяющейся задачи создаётся следующий экземпляр с теми же тегами, заметками и подзадачами.

## 3. Функциональные требования

### 3.1. Задачи

- FR-1. Создание, редактирование, завершение, отмена завершения, удаление (корзина 30 дней), дублирование.
- FR-2. Свойства: срок (дата или дата+время), дата начала, приоритет 1–3, повтор, оценка времени, теги, локация, URL, список, заметки, исполнитель.
- FR-3. Отложить (postpone): сдвиг срока на 1 день одним действием; счётчик откладываний виден в карточке.
- FR-4. Массовые операции над выделенными задачами: завершить, отложить, сменить список/приоритет/срок, добавить/удалить теги, удалить.
- FR-5. Подзадачи (Pro): вложенность до 3 уровней, прогресс «2 из 5» у родителя.
- FR-6. Отмена последнего действия (undo) в течение 10 с через тост.

### 3.2. Быстрый ввод (Smart Add)

Одна строка разбирается на свойства задачи. Распознанные токены подсвечиваются в поле ввода по мере набора; есть автодополнение списков, тегов и локаций.

| Символ | Свойство | Пример |
| --- | --- | --- |
| `^` | Срок | `^завтра 17:00`, `^пт`, `^25 дек` |
| `~` | Дата начала | `~понедельник` |
| `!` | Приоритет | `!1`, `!2`, `!3` |
| `#` | Список или тег (список приоритетнее при совпадении) | `#Работа`, `#звонки` |
| `*` | Повтор | `*каждую неделю`, `*after 2 weeks` |
| `@` | Локация | `@офис` |
| `=` | Оценка | `=30 мин`, `=1ч` |
| `+` | Передать контакту | `+anna` |
| `//` | Заметка | `// уточнить бюджет` |

Парсер дат поддерживает русский и английский: относительные даты («через 3 дня»), дни недели, «сегодня/завтра/послезавтра», время в 12/24-часовом формате. При отключённом Smart Add символы трактуются буквально.

### 3.3. Списки и теги

- FR-7. Пользовательские списки: создать, переименовать, архивировать, удалить, задать порядок.
- FR-8. Системные представления: «Все задачи», «Сегодня», «Завтра», «На этой неделе», «Просрочено», «Входящие», «Отправленные», «Выполненные».
- FR-9. Теги с автодополнением, облако тегов в сайдбаре, цвет тега (Pro).

### 3.4. Поиск и умные списки

- FR-10. Полнотекстовый поиск по названиям и заметкам.
- FR-11. Язык запросов с операторами `AND`, `OR`, `NOT`, скобками и полями: `list:`, `tag:`, `priority:`, `due:`, `dueBefore:`, `dueWithin:"1 week"`, `completed:`, `isRepeating:`, `hasSubtasks:`, `location:`, `isShared:`, `addedWithin:`, `postponed:>2`, `timeEstimate:"<1 hour"`.
- FR-12. Сохранение запроса как умного списка; конструктор запроса в UI для тех, кто не хочет писать синтаксис.

### 3.5. Сортировка и группировка

- FR-13. Бесплатно: по приоритету, сроку, названию.
- FR-14. Pro: произвольная сортировка (drag-and-drop), группировка по списку, тегу, приоритету, сроку, локации; комбинация до 2 уровней.

### 3.6. Напоминания

- FR-15. Каналы: push (Android, браузер), email, ежедневная сводка на email в выбранное время.
- FR-16. Смещения по умолчанию задаются в настройках (например, «за 15 минут» и «в 8:00 в день срока»); у задачи — свои.
- FR-17. Из уведомления: «Выполнить», «Отложить на 1 ч / завтра», «Открыть».
- FR-18. Напоминания по геолокации на Android при входе в радиус локации (Pro).

### 3.7. Совместная работа

- FR-19. Приглашение контакта по email; общий список с правами «просмотр» или «редактирование». Бесплатно — до 2 контактов, Pro — без ограничений.
- FR-20. Передача задачи контакту (попадает к нему во «Входящие», у отправителя — в «Отправленные»).
- FR-21. Лента активности и уведомления об изменениях в общих списках.

### 3.8. Прочее

- FR-22. Добавление задач по email: у каждого аккаунта уникальный входящий адрес; тема → название, Smart Add работает в теме.
- FR-23. Обзор «задачи рядом»: карта с задачами по локациям.
- FR-24. Печать и экспорт списка (PDF, CSV, iCal-фид задач со сроками).
- FR-25. Импорт из CSV и популярных менеджеров задач.

## 4. UX веб-приложения

Веб-версия построена по трёхпанельной схеме: навигация слева, список задач в центре, карточка выбранной задачи справа. Повторяется логика RTM — быстрый ввод сверху, клавиатурное управление, детали без перехода на другую страницу; оформление своё.

### 4.1. Каркас экрана

| Зона | Ширина | Содержимое |
| --- | --- | --- |
| Верхняя панель | 56 px высота | Логотип, глобальный поиск с подсказками синтаксиса, кнопка синхронизации/статус, уведомления, аватар-меню (настройки, тариф, выход) |
| Сайдбар | 248 px, сворачивается до 64 | Блоки: «Входящие», системные представления, «Списки», «Умные списки», «Теги», «Локации», «Контакты»; счётчики задач; «+» у каждого блока |
| Список задач | гибкая, мин. 420 px | Заголовок списка + меню списка, табы «Невыполненные / Выполненные», поле Smart Add, панель сортировки, строки задач |
| Карточка задачи | 400 px, закрывается | Название (inline-редактирование), свойства в виде строк «ключ — значение», подзадачи, заметки, вложения, история |

На ширине 768–1023 px карточка открывается поверх списка как выезжающая панель; ниже 768 px — мобильная схема с нижней навигацией, как в Android.

### 4.2. Строка задачи

- Слева: чекбокс; цветная полоса приоритета по левому краю (1 — сильный акцент, 2 — средний, 3 — слабый).
- Название; справа — чипы тегов, иконки (повтор, заметка, вложение, локация, общий), срок (просрочено — красным, сегодня — жирным).
- Наведение: кнопки «Выполнить», «Отложить», «Ещё». Клик выделяет и открывает карточку; Ctrl/Shift-клик — множественное выделение.
- При выделении нескольких задач панель сортировки сменяется панелью массовых действий.

### 4.3. Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `T` | Новая задача (фокус в Smart Add) |
| `C` | Завершить выделенные |
| `P` | Отложить |
| `1` `2` `3` `4` | Приоритет 1/2/3/без приоритета |
| `D` | Срок |
| `S` | Добавить теги |
| `R` | Переименовать |
| `F` | Повтор |
| `M` | Переместить в список |
| `J` / `K` | Следующая / предыдущая задача |
| `I` | Выделить / снять выделение |
| `A` / `N` | Выделить все / ничего |
| `/` | Поиск |
| `Ctrl+Z` | Отменить |
| `Delete` | Удалить |
| `?` | Шпаргалка по клавишам |

### 4.4. Ключевые сценарии

1. **Быстрое добавление:** `T` → ввод `Купить молоко ^завтра #Покупки !2` → Enter → задача появляется в нужном списке, токены видны чипами; поле остаётся в фокусе для следующей.
2. **Разбор входящих:** открыть «Входящие» → `J`/`K` по задачам → `M` переместить, `D` задать срок → пусто = экран «Всё разобрано».
3. **Умный список:** ввести запрос в поиск → «Сохранить как умный список» → имя → появляется в сайдбаре со счётчиком.
4. **Поделиться списком:** меню списка → «Поделиться» → email контакта + права → приглашение; у получателя — баннер принятия.
5. **Онбординг:** 3 шага (часовой пояс и язык, первые списки из шаблонов, разрешение на уведомления) + интерактивная подсказка по символам Smart Add.

### 4.5. Состояния

Для каждого списка определены: пустое состояние с подсказкой, загрузка (скелетоны строк), офлайн (баннер «Изменения сохранятся при подключении»), ошибка синхронизации (повтор + детали), конфликт (диалог выбора версии только для полей, изменённых с двух сторон).

## 6. Визуальная система

Общая библиотека токенов для веба и Android; бренд Taskly — спокойный, плотный по информации интерфейс с одним акцентным цветом. Конкретные значения утверждает дизайнер; ниже — структура и стартовые значения.

| Токен | Светлая тема | Тёмная тема | Назначение |
| --- | --- | --- | --- |
| color.accent | #2F6FED | #7AA2FF | Кнопки, FAB, активный пункт меню |
| color.priority.1 | #E5484D | #FF6B6F | Полоса приоритета 1 |
| color.priority.2 | #F28C28 | #FFA857 | Приоритет 2 |
| color.priority.3 | #3E9BD1 | #6CBDEB | Приоритет 3 |
| color.overdue | #D93036 | #FF6369 | Просроченный срок |
| color.surface | #FFFFFF | #16181D | Фон карточек |
| color.background | #F5F6F8 | #0E0F12 | Фон приложения |

- **Типографика:** Inter (веб), Roboto Flex (Android); шкала 12 / 14 / 16 / 20 / 24; строка задачи — 15 px / 15 sp.
- **Отступы:** сетка 4 px; высота строки задачи 44 px (компактный режим — 36 px).
- **Иконки:** собственный набор на основе Material Symbols Rounded, 20/24 px.
- **Темы:** светлая, тёмная, системная; 12 цветовых тем акцента (Pro — дополнительные 20).
- **Плотность:** обычная и компактная.
- **Доступность:** WCAG 2.1 AA; контраст текста ≥ 4.5:1; приоритет передаётся не только цветом (номер в подсказке и для скринридера); поддержка TalkBack, системного масштаба шрифта до 200 %, полное управление с клавиатуры в вебе, видимый фокус.
- **Локализация:** русский и английский в v1; все строки в ресурсах, форматы дат по локали.

## 7. Синхронизация, офлайн, интеграции, API

Клиенты работают по принципу local-first: каждое действие сначала пишется в локальную базу и очередь операций, затем отправляется на сервер; интерфейс никогда не ждёт сети.

### 7.1. Синхронизация

- Дельта-синхронизация по курсору: `GET /sync?since=<cursor>` возвращает изменённые сущности, клиент шлёт пакет операций `POST /sync/ops`.
- Реальное время: WebSocket-канал на пользователя; на Android — FCM data-сообщение «есть изменения» при свёрнутом приложении.
- Конфликты — по полям (last-writer-wins на уровне поля с серверным временем); завершение задачи всегда побеждает переименование; удаление побеждает правку, но задача восстановима из корзины.
- Идемпотентность: каждая операция несёт `op_id`; повтор отправки безопасен.

### 7.2. Офлайн

- Веб: IndexedDB + Service Worker (PWA), полный доступ к спискам за последние 90 дней и всем невыполненным задачам.
- Android: Room (SQLite), WorkManager для отправки очереди при появлении сети.
- Напоминания на Android срабатывают офлайн (планируются локально).

### 7.3. Интеграции

| Интеграция | Тариф | Что делает |
| --- | --- | --- |

| Email-to-task | Free | Уникальный адрес для создания задач письмом |

### 7.4. Публичный API (основные ресурсы)

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET / POST | `/v1/tasks` | Список с фильтром `q=` (тот же язык запросов) / создание, поддерживает `smart_add=true` |
| PATCH / DELETE | `/v1/tasks/{id}` | Изменение / удаление |
| POST | `/v1/tasks/{id}/complete` | Завершение (с генерацией следующего повтора) |
| GET / POST | `/v1/lists` | Списки и умные списки |
| GET / POST | `/v1/tags`, `/v1/locations` | Справочники |
| POST | `/v1/webhooks` | Подписка на события `task.created`, `task.completed`, `task.updated` |

Лимиты: 1 запрос/с и 10 000 в сутки на токен (Pro — 5/с, 100 000).

### 8.2. Нефункциональные требования

- **Производительность:** открытие списка из 1 000 задач ≤ 300 мс (из локальной базы); отклик на действие ≤ 100 мс; холодный старт Android ≤ 1.5 с на среднем устройстве; первая загрузка веба ≤ 2.5 с LCP на 4G.
- **Синхронизация:** изменение видно на другом устройстве онлайн за ≤ 2 с (p95).
- **Надёжность:** доступность API 99.9 % в месяц; RPO 15 мин, RTO 1 ч; ежедневные бэкапы с хранением 30 дней.
- **Напоминания:** доставка push не позже 60 с от назначенного времени (p99).
- **Безопасность:** TLS 1.2+, шифрование данных на диске, хеш паролей Argon2id, 2FA (TOTP), OAuth Google; токены API с областями доступа.
- **Приватность:** соответствие GDPR и 152-ФЗ (локализация данных российских пользователей — уточнить с юристом); экспорт и удаление аккаунта самим пользователем.
- **Масштаб:** 1 млн пользователей, 200 млн задач без смены архитектуры.
- **Качество:** покрытие тестами доменной логики ≥ 80 %; общий набор тест-кейсов Smart Add (≥ 500 строк ввода) для всех платформ.
